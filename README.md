# PromptAI

> Transform your images & videos into professional AI prompts.

**PromptAI** is a free, ultra-fast Progressive Web App (PWA) that analyzes your images and videos to generate professional prompts for AI engines like Midjourney v6, DALL-E 3, Runway Gen-3, Sora, and Luma.

## Features

- 🖼️ Image & Video Analysis
- 🤖 Multiple AI Engine Support (Midjourney, DALL-E, Runway, Sora, Luma)
- 🎨 10+ Artistic Styles
- 🌍 6 Languages (EN, FR, DE, ES, ZH, AR)
- 🌙 Dark & Light Mode
- 📱 Installable PWA
- ⚡ Edge-deployed on Vercel

## Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- Cloudflare Workers AI (LLaVa)
- Google Gemini API
- Google AdSense
- PWA (Service Worker + Manifest)

## Deployment

Hosted on Vercel at `prompt.wdbloog.com`.
